# Security

ClaudioXP runs hooks on your machine while Claude Code works. If you find a way to get around
its guard rails, or anything else that could hurt its users, please tell us in private first.

## Supported versions

Only the latest version gets security fixes. Update with:

```
claude plugin update claudio@claudio-plugin
```

## How to report

Please don't open a public issue. Use one of these:

- **GitHub:** the repo's **Security** tab → **Report a vulnerability**
  ([open the form](https://github.com/leandrodalbo/claudio-plugin/security/advisories/new)).
- **Email:** claudioxpplugin@gmail.com

Tell us:

- what the problem is and what someone could do with it,
- how to make it happen, step by step,
- your version (`claude plugin list`), Claude Code version (`claude --version`) and OS.

## What happens next

- You get a first answer within 7 days.
- We check it, fix it, and release the fix.
- We say thanks in the release notes, with your name if you want it.
