Install

Embrace change without losing control.

Guard rails for Claude Code. Claude types fast; you decide what ships.

INSTALL

claude plugin marketplace add leandrodalbo/claudio-plugin
claude plugin install claudio@claudio-plugin

Needs Claude Code, git and Python 3.11+. Then run /claudio:init in your project.

Who it's for

ClaudioXP is for software engineers who want AI's speed and keep responsibility for what they ship.

1

You need the fundamentals.

It guides an engineer; it does not stand in for one. If you can't judge a change, ClaudioXP can't help you.

2

Know your paradigm.

Object-oriented, functional or structured, and why.

3

You don't need to be an expert in the language.

Bring the engineering know-how, and ask Claude to explain the language as you go.

4

It is not for "vibe" coding.

Every cycle stops for your decision: the spec, the tests, the review, the commit.

The spirit

The value is in the problem solved, not in the code written.

Code is cheap now. What counts is the right problem, solved well.

Embrace change.

New tools are here. Use them, keep the craft, and keep creating value.

No "vibing": knowledge and experience are required.

You judge every change. Your experience is what makes the result good.
